# ハーネス改善の記録

ハーネス（AI エージェントの作業環境: CLAUDE.md、steering、rules、スキル、hooks、lint、テスト、CI）は、使いながら鍛えていくもの。**同じ失敗を、次からは仕組みで防ぐ**ために、見つけた不具合や穴をここに記録する。

## 書く人とタイミング

- **エージェント**: 作業中にハーネスの不具合や穴を見つけたとき。改修の完了報告（`impl-complete`）でも必ず見直す
- **人間**: レビューで指摘したことのうち、次から仕組みで防ぎたいもの（エージェントに「ハーネスに還元して」と頼んでもよい）

## 直し方の選び方

| 種類 | 置き場所 | 向いているもの |
| --- | --- | --- |
| **事後に検出する（優先）** | lint のルール、テスト、hook、CI、ハーネスの自己点検 | 機械的に判定できるもの（禁止した書き方、層の依存、必須の手順の抜け） |
| 事前に方向を示す | steering、`.claude/rules`、スキル、手本の追加 | 判断が必要なもの（設計の方針、UI のトーン） |

文章のルールを足す前に、「lint や hook で止められないか」を必ず考える。CLAUDE.md とルールは短く保つ。
