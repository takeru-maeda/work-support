# 移行時点の基準（工数登録）

### 要確認

1. **送信を全部保存するか全部保存しないかにしてよいか**: 今は、途中の要素で失敗すると、それより前の行と作った案件が残る。画面は入力を残すので、送り直すと 2 重になる。全行を保存したあとに候補の一覧の作り直しが失敗したとき（500）も、全行が 2 重になる。effort-ingest-gas でも同じ問題があり、「1 回の送信を全部保存するか全部保存しないかにする」と決めている。推奨: 同じく、まとめて保存する（DB の関数で 1 つのトランザクションにする）。候補の一覧の作り直しは、保存のあとの失敗を 500 にせず、保存の成功として返す。P6 以降に改修の記録を通す
2. **同じ日に 2 回送ったら足してよいか**: 今は、前の登録を置き換えずに行を足す（1 日に何回かに分けて登録できる）。同じ案件・同じタスクの行も別々に残る。推奨: 今のまま（分けて登録する使い方を残す）。2 重の登録を防ぐのは要確認 1 で行う
3. **入力欄の中の Ctrl / Cmd + Z をフォーム全体の undo にしてよいか**: 今は、メモや数値の欄の中でもフォーム全体の undo になり、キー入力 1 文字ごとに 1 歩戻る。ブラウザの入力欄の取り消しは使えない。推奨: 今のまま（1 文字ずつ戻せ、欄をまたいでも戻せるので、困っていなければ変えない）。ただし確認のダイアログを開いている間は効かないようにする

| 2 | 同じ日に送ったら足す今の動きのまま（1 日を分けて登録できる） |

| 4 | 下の「見つけた不具合」は、すべて P6 で直す |

### 見つけた不具合（計画書の P6 に足すもの）

- 100 時間以上で DB の桁あふれの 500（スキーマで 100 未満にして 400 にする。画面も止める）
- 負の値を画面で止めず、送ってから失敗の 1 つのトーストになる
- 大文字小文字の扱いがそろっていない（effort-ingest-gas の判断と同じく、区別する側にそろえる）
- 同じ送信の中で、使い回したタスクの ID が案件を確かめない
- 画面のタスクの候補だけが案件名の大文字小文字を区別しないので、「案件A」があるところで「案件a」と打ってタスクを選ぶと 400 になり、「案件a」だけが作られて残る（API の側は確かめた）
- 完了メールの失敗が `error_logs` に残らない。GAS が JSON 以外を返したときの扱いが無い
- 完了メールの【集計】の前の空行が 2 行
- 同じ案件・タスクを画面で 2 つ入れられる（名前を打ち込むと候補の除外をすり抜ける）
- 案件名を打っている途中で、既存の案件名と一致した瞬間に候補の一覧が閉じる
- 開発用サーバーで undo の 1 歩が 2 回ずつ記録される（履歴の記録を状態の更新の外に出す）
- 案件を変えたときに、2 つ目以降のタスクの「必須入力」が消えないことがある（コードから。直すときに確かめる）
- 集計の案件名が「未設定の案件」のまま、`useEffortSubmission` の依存配列（どちらもコードの `TODO(P6)`。計画書の P6 に既にある）

## 仕様レビュー（spec-reviewer）

- Major 2 件、Minor 10 件を受けて spec.md と記録を直した。Major は、検証が確認のダイアログを開く前に走ること（AC-17 の書き方がコードと違っていた）と、大文字小文字だけが違う案件でタスクの候補を選ぶと 400 になり案件だけが残る経路の書き漏れ。Minor は、全行を保存したあとの失敗でも 2 重になること、案件欄を 1 文字直すと全タスクが空になること、送信中の編集が消えること、AC-05 が不具合（500）を期待値にしていたこと、「読み込み中」の対象、集計のまとめ方、メールの案件の並び、メールの日付のタイムゾーン、frontmatter の `code`
- 事実の確認（ローカルの Supabase と `pnpm dev:local`）: 完了メールの全文、100 時間で 500、途中の失敗で前の行が残ること、失敗した送信で作った案件が候補にすぐ出ないこと、「案件a」が「案件A」と別に作られること、同じタスクの 2 行がまとめられないこと、大文字小文字だけが違う案件とタスクの ID で 400 になり案件が残ること、入力欄の中の Ctrl / Cmd + Z がフォーム全体の undo になること、開発用サーバーで undo の 1 歩が 2 回ずつ記録されること、既存の案件名と一致した瞬間に候補の一覧が閉じること

## 対象外

- 下書き（effort-draft）、Google Form からの取り込み（effort-ingest-gas）、工数一覧（effort-list）
