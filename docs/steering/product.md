# プロダクト概要

仕事サポートアプリ（Work Support）は、個人の日々の業務を支える Web アプリケーション。工数の記録、目標の進捗管理、週報の作成を一つにまとめ、業務の見える化と振り返りを助ける。

## 主な機能

1. **工数管理**: 案件・タスク単位で見積と実績を記録する。Web 画面からの登録に加え、Google Form（GAS）からのテキスト取り込みにも対応する。下書きは自動で保存し、複数端末間で同期する。
2. **目標管理**: 期間を決めて目標と重み（合計 100%）を設定し、週ごとの進捗を記録・振り返る。
3. **週報**: 週の工数サマリー、ミッション、目標の進捗を整形して表示し、コピーして使える。
4. **アカウント**: Supabase 認証によるログイン・新規登録、プロフィール、設定（メール通知、テーマ）、アカウント削除。

機能ごとの詳しい振る舞いは `docs/specs/<feature>/spec.md` を正とする。

## 想定する使い方

- 毎日の工数を記録し、上長への報告や自己管理に使う
- 期間目標を決め、達成度を週次で振り返る
- 週報を自動で組み立て、定型作業の時間を減らす

## 大事にしていること

- **仕様書とコードの一致**: 機能ごとの仕様書（`docs/specs/`）を現在の姿の正として保ち、改修のたびに更新する
- **型で守る API 契約**: `packages/shared` の Zod スキーマをフロントエンドとバックエンドで共有し、入出力のずれを防ぐ
- **小さく保つ構成**: pnpm ワークスペースのモノレポで、api / web / shared の 3 パッケージに責務を分ける
